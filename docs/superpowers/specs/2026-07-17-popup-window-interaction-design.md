# 历史窗口交互调整设计

**日期：** 2026-07-17
**状态：** 已确认
**范围：** 调整历史列表弹窗的关闭、拖动、任务栏可发现性和列表交互。

## 目标

避免用户点击窗口外部时历史窗口意外消失，同时保持当前轻量、无边框的视觉风格。

## 交互规则

- 历史窗口失去焦点时保持显示，不再自动隐藏。
- 窗口顶部增加自定义标题栏，标题栏空白区域可用鼠标拖动窗口。
- 标题栏右上角增加明确的关闭按钮“×”。
- 点击关闭按钮或按 Esc 时隐藏历史窗口，不退出后台程序。
- 选择并恢复一条历史内容后，继续自动隐藏历史窗口。
- 再次按全局快捷键时，已显示的历史窗口被激活并获得焦点。
- 历史窗口显示时在 Windows 任务栏中显示“剪贴板历史”入口。
- 历史窗口隐藏后任务栏入口同步消失，后台继续只保留托盘图标。
- 单击历史记录只改变当前选中项，不立即恢复剪贴板内容。
- 双击普通记录区域或按 Enter 时恢复当前记录并隐藏窗口。
- 单击收藏星标只切换收藏状态；双击星标区域不恢复内容。

## 界面设计

- 保留现有无边框窗口、尺寸、搜索框、筛选栏、时间线和底部快捷键提示。
- 自定义标题栏位于搜索框上方，显示“剪贴板历史”和右上角关闭按钮。
- 关闭按钮采用与现有主题一致的扁平样式，悬停时提供清晰反馈。
- 拖动只从标题栏及标题文字区域开始，避免与搜索框、筛选按钮和历史列表交互冲突。
- 不启用始终置顶；窗口被其他程序遮挡时，用户通过任务栏按钮重新激活窗口。
- 从任务栏或其他程序切回历史窗口时，时间线立即刷新，显示后台期间捕获的新内容。
- 文本记录固定显示最多两行，超出部分显示省略号，并严格裁剪在当前记录区域内。
- 适当增加固定行高，为时间、两行摘要和底部分隔线保留稳定间距。

## 实现方式

- 删除窗口的 Deactivate 自动隐藏处理。
- 使用无边框窗体常见的 Win32 拖动方式：标题栏按下鼠标左键时发送非客户区标题栏拖动消息。
- 关闭按钮和 Esc 共用同一隐藏行为，确保后台监听和托盘图标继续运行。
- 保留恢复内容后的自动隐藏逻辑。
- 将无边框历史窗体的 `ShowInTaskbar` 设置为 `true`，依赖 WinForms 在窗体显示和隐藏时自动维护任务栏入口。
- 在窗体 `Activated` 事件中刷新时间线，避免任务栏重新激活后显示旧数据。
- 使用带两行限制和省略号的文本绘制方式，避免 GDI+ 文本越过固定行边界。
- 将普通区域的单击处理改为只选中；在双击事件中恢复选中记录。收藏星标继续在单击事件中单独处理。

## 测试与验收

- 自动化测试确认窗口仍为无边框且具有标题栏和关闭按钮。
- 自动化测试确认失焦处理不再绑定自动隐藏逻辑。
- 自动化测试确认关闭按钮隐藏窗口而不是销毁窗体。
- 自动化测试确认历史窗体启用任务栏入口，并在隐藏时保持可再次显示。
- 自动化测试确认窗体激活时重新查询历史记录。
- 自动化测试确认文本摘要的绘制区域不超过当前列表项边界。
- 自动化测试确认单击只选中，双击或 Enter 才调用恢复操作。
- 人工验证窗口可从标题栏拖动，点击窗口外不消失，Esc 和“×”可以关闭，再次 Alt+V 可以重新打开。
- 人工验证窗口显示时可从任务栏重新激活，隐藏后任务栏入口消失。

## 非目标

- 不增加最小化、最大化或调整窗口尺寸功能。
- 不增加始终置顶或后台常驻任务栏入口。
- 不改变搜索、筛选、收藏、删除和恢复内容的业务行为。
- 不使用按文本长度动态变化的列表项高度，保持滚动和分页行为稳定。
- 不改变托盘菜单、快捷键设置或剪贴板存储逻辑。
