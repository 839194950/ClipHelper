# 剪贴板历史高帧率滚动与可拖动滚动条设计

日期：2026-07-22

## 背景

当前历史窗口已经消除了明显闪烁和阻塞，但连续滚动的视觉帧距仍不够均匀，用户感受类似游戏帧率偏低。当前自绘时间线具备像素级滚动和双缓冲，但绘制路径仍会在每帧生成文本、缩放图片，并且右侧滚动条仅用于显示，不能点击或拖动。

本次采用方案 A：保留连续历史列表，在不增加第三方依赖的前提下优化绘制热路径，并让右侧滚动条支持点击和拖动。

## 目标

- 提高滚轮滚动时的视觉连贯性和输入响应速度。
- 消除绘制热路径中的重复字符串处理、图片缩放和临时 GDI 对象分配。
- 支持鼠标拖动滚动条滑块。
- 支持点击滚动条轨道按一屏距离跳转。
- 保持现有剪贴板监听、搜索、筛选、分页加载、选择和应用行为。

## 非目标

- 不改成固定每页 15 条的分页界面。
- 不迁移到 WPF、WinUI 或第三方 UI 框架。
- 不加入惯性物理、弹性回弹或复杂手势。
- 不改变历史记录数据库查询每批 100 条的策略。
- 不改变窗口大小、快捷键和任务栏行为。

## 方案概览

继续使用自绘的 `BufferedListBox` 作为唯一时间线控件。优化分为三层：

1. 数据展示缓存：在 `ClipboardEntryView` 创建时计算稳定的摘要和时间字符串，并准备实际显示尺寸的缩略图。
2. 绘制热路径：`PopupListRenderer` 使用缓存资源和 `TextRenderer`，绘制期间不做字符串转换、字体创建或大图缩放。
3. 输入与滚动条：`BufferedListBox` 使用真实经过时间推进滚动动画，并实现滑块命中、拖动和轨道点击。

## 数据展示缓存

### 文本缓存

`ClipboardEntryView` 在构造时生成并保存：

- `DisplayText`：文本内容去除换行后最多保留 180 个字符；图片记录保存尺寸摘要。
- `DisplayTime`：使用本地时间格式 `MM-dd HH:mm`。

收藏状态改变时只替换 `ClipboardEntry`，上述缓存不需要重新计算。

### 缩略图缓存

`PopupForm.LoadThumbnail` 读取已有缩略图文件后，立即创建适合列表显示区域的位图。缩放时保持宽高比并居中放入最大 `58 × 58` 的透明画布。

列表滚动过程中只绘制该小位图，不再反复把最高约 `320 × 220` 的文件缩放到卡片尺寸。

原始文件和数据库路径不变；缓存位图仍由 `ClipboardEntryView.Dispose` 释放。

## 绘制优化

`PopupListRenderer` 继续集中管理画刷、画笔和字体的生命周期，并做以下调整：

- 时间和摘要使用 WinForms `TextRenderer.DrawText`。
- 使用 `TextFormatFlags.EndEllipsis`、`WordBreak` 和 `NoPadding` 保持两行裁剪。
- 图片按原尺寸直接绘制到缓存位图对应区域。
- 只绘制可见记录和右侧滚动条。
- 滚动位置没有变化时不调用 `Invalidate`。
- 不恢复持续悬停动画；悬停状态仍即时切换。

## 滚轮动画

滚轮输入继续使用平滑过渡，但时间推进改为基于 `Stopwatch.GetTimestamp` 的真实经过时间：

- 目标动画时长为 96ms。
- UI 定时器仅用于请求下一帧，不假定每次 Tick 固定为 16ms。
- 每帧使用真实 delta 推进 `PopupAnimation`。
- 连续滚轮输入以当前视觉位置为起点，并在原目标位置上继续累加。
- 当新位置与旧位置相同时跳过重绘。
- 到达顶部或底部时立即停止计时器。

该方案不承诺固定显示器刷新率，但避免由于消息循环延迟造成动画速度忽快忽慢。

## 可拖动滚动条

### 外观

- 默认滑块宽度为 4px。
- 鼠标悬停或拖动时宽度增加到 7px。
- 使用主题次级文字颜色的半透明版本。
- 内容不足一屏时完全隐藏。

### 命中区域

视觉滑块较窄，但鼠标命中区域向左扩展到 14px，降低操作难度。

### 拖动

- 左键按下滑块后调用 `Capture = true`。
- 记录按下位置和滑块顶部的偏移量。
- 鼠标移动时将滑块位置映射为 `0..MaximumScrollOffset`。
- 拖动期间停止滚轮动画，并直接设置滚动位置。
- 松开鼠标或失去捕获时结束拖动。

### 轨道点击

- 点击滑块上方，向上移动约一个可视区域高度。
- 点击滑块下方，向下移动约一个可视区域高度。
- 轨道跳转使用短暂的 96ms 平滑过渡。

## 分页加载

数据库仍按每批 100 条加载。

滚轮、拖动或轨道跳转后，`PopupForm.TryLoadNextPage` 继续根据 `TopIndex` 和可见记录数判断是否接近尾部。拖动到已加载内容底部时可以触发下一批加载，但同一时间只允许一个查询。

## 交互兼容性

以下行为必须保持：

- 单击卡片只选中。
- 双击卡片或按 Enter 应用记录。
- 单击星标切换收藏，双击星标不能应用记录。
- Delete 删除选中记录。
- Esc 和右上角关闭按钮隐藏窗口。
- 失去焦点不自动关闭。
- 鼠标拖动标题栏仍可移动窗口。
- 搜索、类型筛选和任务栏重新激活仍会刷新列表。

## 测试策略

### 单元与集成测试

- 验证重复读取 `DisplayText` 和 `DisplayTime` 使用稳定缓存。
- 验证加载后的缩略图尺寸不超过 `58 × 58`。
- 验证滚动动画按真实时间推进，并在相同位置时不产生额外帧。
- 验证滚动条滑块命中、拖动映射和边界限制。
- 验证轨道点击按一屏距离改变目标位置。
- 验证拖动期间停止已有滚轮动画。
- 回归验证点击、双击、收藏、键盘、搜索和自动加载。

### 桌面验收

- 使用包含文本和图片的至少 100 条历史记录连续快速滚动。
- 鼠标拖动滑块从顶部到中部和底部，列表实时跟随。
- 点击轨道上下区域，确认按一屏跳转。
- 在滚动过程中快速反向滚轮，确认无停顿、跳跃或动画堆积。
- 确认 CPU 占用在停止滚动后立即恢复，计时器不持续运行。

## 验收标准

- 滚动无闪烁、无明显输入延迟，动画帧距比当前版本更均匀。
- 滑块可点击、拖动并准确到达顶部和底部。
- 点击轨道可以向相应方向跳转约一屏。
- 绘制过程中不重复生成摘要、时间字符串或缩放缩略图。
- 所有自动化测试通过，严格构建为 0 警告、0 错误。
- 不新增第三方运行时依赖。
