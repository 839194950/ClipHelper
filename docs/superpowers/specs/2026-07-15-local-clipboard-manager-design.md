# 本地剪贴板工具设计说明

**日期：** 2026-07-15  
**状态：** 已批准  
**目标平台：** Windows 10/11 x64

## 1. 产品目标

构建一个轻量、完全离线运行的 Windows 剪贴板历史工具。程序在后台静默监听剪贴板，保存最近复制的纯文本和图片；用户通过全局快捷键快速打开历史窗口，选择内容并恢复到系统剪贴板。

产品体验参考 G-Helper 的轻量化理念：低干扰、托盘常驻、无需复杂安装、需要时快速呼出。首版不追求完整知识管理能力，重点保证剪贴板捕获稳定、检索迅速、资源占用可控。

## 2. 已确认需求

- 仅支持 Windows 10/11。
- 使用 C#、WinForms 和 .NET 10 LTS。
- 以 win-x64 自包含单文件 EXE 发布。
- 默认随 Windows 启动，可在设置中关闭。
- 默认全局快捷键为 Alt+V，允许用户修改。
- 支持纯文本和图片，不支持文件、HTML 或富文本。
- 选择历史项后只恢复到系统剪贴板，不自动粘贴。
- 支持搜索、单条删除、清空历史和收藏；清空时可明确选择是否包含收藏。
- 默认最多保留 500 条普通记录，普通记录保留 30 天。
- 收藏记录不参与数量、时间和图片缓存自动清理。
- 程序完全离线，可暂停监听和一键清空数据。

## 3. 用户体验设计

### 3.1 后台运行

程序启动后不显示主窗口，直接进入系统托盘并开始监听剪贴板。程序不安装 Windows 服务，也不要求管理员权限。

托盘菜单包含：

- 打开剪贴板历史
- 暂停或恢复监听
- 设置
- 清空历史
- 退出

暂停监听后，托盘图标应呈现明确的暂停状态。退出操作停止监听并释放全局快捷键。

### 3.2 快捷呼出窗口

按 Alt+V 后，在鼠标所在显示器的中央偏上位置显示无边框弹窗。窗口不出现在任务栏中，失去焦点时自动隐藏。

窗口采用已批准的“统一时间线”布局：

- 顶部为搜索框，打开窗口时自动获得焦点。
- 搜索框下方提供“全部、文本、图片、收藏”筛选。
- 文本与图片按复制时间倒序混合排列。
- 文本项展示时间、内容摘要和收藏状态。
- 图片项展示缩略图、尺寸、时间和收藏状态。
- 当前选中项有清晰但克制的高亮状态。

键盘操作：

- 上/下方向键：切换选中记录。
- Enter：把选中记录恢复到系统剪贴板并关闭窗口。
- Delete：删除选中记录。
- Esc：关闭窗口。

鼠标单击记录与 Enter 行为一致。点击收藏按钮只切换收藏状态，不触发恢复操作。

### 3.3 设置窗口

首版设置保持简洁，只包含：

- 开机启动开关。
- 全局快捷键录制与冲突提示。
- 数据目录展示与打开按钮。
- 普通记录数量和保留时间的只读说明。
- 当前图片缓存占用展示。

首版不开放复杂的清理规则编辑，以保持行为明确且易于测试。

## 4. 系统架构

应用为单进程 WinForms 程序，使用 ApplicationContext 管理托盘生命周期，并通过隐藏消息窗口接收 Windows 剪贴板通知。

核心模块：

### 4.1 TrayApplication

- 管理程序生命周期和托盘图标。
- 注册托盘菜单与开机启动设置。
- 保证只有一个程序实例运行。
- 重复启动时通知已有实例打开历史窗口。

### 4.2 ClipboardMonitor

- 使用 Windows 原生剪贴板变化通知，不执行高频轮询。
- 在 STA 线程读取文本或位图。
- 剪贴板暂时被其他应用占用时进行有限次数的短延迟重试。
- 忽略不支持的数据格式。
- 标记由本程序恢复的剪贴板写入，避免产生新的历史记录。

### 4.3 HistoryService

- 对捕获内容进行标准化、哈希和去重。
- 连续复制相同内容时更新时间并移动到列表顶部，不创建重复项。
- 协调数据库、图片文件、查询、删除、收藏和清理策略。
- UI 不直接访问数据库或图片目录。

### 4.4 HistoryStore

- 使用 SQLite 保存记录元数据和文本正文。
- 提供按时间分页、类型筛选、收藏筛选和文本搜索。
- 使用事务保证记录与状态更新的一致性。

### 4.5 ImageStore

- 将位图编码为 PNG 文件。
- 根据内容哈希生成稳定文件名。
- 生成列表使用的缩略图，避免每次显示完整原图。
- 删除图片记录时同步删除原图和缩略图。
- 启动时清理数据库中不存在的无主图片文件。

### 4.6 PopupWindow

- 显示统一时间线、搜索和筛选结果。
- 使用分页或按需加载，避免一次解码全部图片。
- 复用缩略图并在窗口隐藏时释放无用图像资源。
- 负责键盘和鼠标交互，但不包含存储规则。

### 4.7 SettingsStore

- 使用 settings.json 保存快捷键、开机启动和窗口相关设置。
- 设置文件损坏时回退到默认配置并保留损坏副本。

## 5. 数据设计

数据根目录为：%LocalAppData%\LocalClipboard

建议结构：

    LocalClipboard/
      history.db
      settings.json
      images/
      thumbnails/
      logs/
      recovery/

历史记录至少包含以下字段：

- Id：唯一标识。
- ContentType：Text 或 Image。
- TextContent：文本正文；图片记录为空。
- ContentHash：标准化内容哈希，用于去重。
- ImagePath：图片相对路径。
- ThumbnailPath：缩略图相对路径。
- Width、Height：图片尺寸。
- EncodedSize：PNG 文件大小。
- CreatedAt：首次捕获时间。
- LastUsedAt：最近捕获或恢复时间。
- IsFavorite：收藏状态。

搜索只匹配 TextContent。首版不对图片执行 OCR，也不为图片生成语义信息。

## 6. 保留与清理策略

- 普通记录最多保留 500 条。
- 普通记录最长保留 30 天。
- 图片缓存安全上限为 1 GB。
- 单张图片编码后超过 20 MB 时不保存。
- 收藏记录不参与 500 条、30 天和 1 GB 自动清理。
- 达到限制时按最旧优先删除非收藏记录。
- 清空历史默认只清空非收藏记录；设置或确认对话框中提供“同时清空收藏”的明确选项。
- 自动清理在启动后执行一次，并在新增记录后按需执行，不使用持续轮询任务。

收藏可能使实际磁盘占用超过 1 GB。界面应展示总占用，用户可手动删除收藏项。

## 7. 快捷键与单实例

- 默认快捷键为 Alt+V。
- 修改快捷键时先尝试注册；注册成功后才保存设置。
- 快捷键被其他程序占用时显示明确提示并保留旧快捷键。
- 应用使用当前 Windows 用户范围的单实例互斥量。
- 第二实例通过本地进程间通信通知第一实例打开弹窗，然后立即退出。

## 8. 开机启动与便携发布

- 开机启动写入当前用户级启动项，不需要管理员权限。
- EXE 可以位于任意可执行目录，数据始终保存在 LocalAppData。
- 移动 EXE 后，用户重新启用开机启动即可刷新路径。
- 发布为 win-x64、自包含、单文件构建。
- 首版不包含安装器、自动更新和 ARM64 构建。

## 9. 隐私与安全边界

- 程序不执行任何网络请求，不包含遥测和账户功能。
- 日志不记录剪贴板正文、图片内容或文本摘要。
- 托盘提供暂停监听和清空历史操作。
- 首版不提供应用黑名单、敏感内容识别或静态数据加密。
- 数据以当前 Windows 用户权限存储；能够访问该用户目录的进程或人员可能读取历史内容。

## 10. 错误处理与恢复

- 剪贴板被占用：有限重试，最终失败时静默跳过并写入不含内容的诊断日志。
- 不支持的数据格式：直接忽略。
- 超大图片：不保存，并通过一次性非打扰提示说明原因。
- 数据库严重损坏：把原数据库移入 recovery 目录，创建新数据库，并显示一次托盘通知。
- 图片写入失败：不提交对应数据库记录。
- 数据库写入失败：删除本次新写入但未引用的图片文件。
- 设置损坏：保留损坏副本并恢复默认值。
- 快捷键注册失败：继续后台监听，提示用户更换快捷键。

日志采用滚动文件，只记录错误类型、时间和堆栈，合计最多约 5 MB。

## 11. 性能目标

- 空闲时不轮询剪贴板，CPU 占用应接近零。
- 常规使用下内存目标不超过约 80 MB。
- 快捷键触发到窗口可交互的目标时间不超过 150 毫秒。
- 列表只加载当前可见范围附近的图片缩略图。
- 搜索输入使用短延迟防抖，避免每次按键执行重复查询。
- 数据库为时间、类型、收藏和哈希字段建立必要索引。

这些数字是首版工程目标，不作为所有硬件上的绝对保证；测试结果应记录实际环境。

## 12. 测试策略

### 12.1 自动化单元测试

- 文本标准化与内容哈希。
- 连续重复内容合并。
- 500 条和 30 天清理规则。
- 收藏记录保护。
- 1 GB 图片缓存清理顺序。
- 文本搜索和类型筛选。
- 设置读写、损坏恢复和快捷键配置验证。

### 12.2 Windows 集成测试

- 文本和图片剪贴板通知。
- 程序恢复内容后不会自我重复捕获。
- 剪贴板被暂时占用时的重试。
- 全局快捷键注册、修改和冲突处理。
- 单实例唤醒。
- 托盘菜单与暂停状态。
- 开机启动配置。

### 12.3 手工界面验证

- 多显示器和不同 DPI 缩放。
- Windows 深色与浅色环境。
- 长文本、空白文本、超宽图片和高分辨率截图。
- 键盘全流程操作和窗口失焦隐藏。
- 大量历史记录下的滚动、搜索和图片加载。

## 13. 首版明确不包含

- 自动粘贴到当前窗口。
- 文件路径、文件列表、HTML 和富文本记录。
- OCR、标签、分组和高级编辑。
- 云同步、账户、网络备份和遥测。
- 应用黑名单和敏感信息自动识别。
- 静态数据加密。
- 自动更新、安装器和 ARM64 发布。

## 14. 首版验收标准

首版完成需要同时满足：

1. 后台能够稳定记录文本和图片，并正确去重。
2. Alt+V 能快速打开统一时间线窗口。
3. 用户可搜索、筛选、恢复、删除和收藏记录。
4. 自动清理不会删除收藏记录，并能同步清理图片文件。
5. 程序可单文件运行、默认开机启动且不需要管理员权限。
6. 暂停、清空和退出行为清晰可靠。
7. 自动化测试覆盖核心数据规则，Windows 集成流程通过。
8. 程序不进行网络访问，日志不包含剪贴板内容。
