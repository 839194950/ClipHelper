# PCL2 风格历史窗口视觉改版设计

**日期：** 2026-07-17
**状态：** 已确认
**方案：** B — 轻量 PCL 混合风
**范围：** 重构剪贴板历史窗口的视觉层级、控件样式和轻量动效，不改变剪贴板业务逻辑。

## 目标

- 借鉴 PCL2 清晰、克制、反馈明确的设计语言，使历史窗口更高级、简约且易于快速扫描。
- 保持后台剪贴板工具的轻量属性，不引入背景图片、重度模糊或第三方 UI 框架。
- 让鼠标悬停、键盘选中、筛选切换、删除和窗口显示具有统一、流畅但不过度的动态反馈。
- 保留现有完全离线、低干扰、文字和图片历史、搜索、收藏、删除及恢复行为。

## 设计原则

### 清晰层级

- 使用单一蓝色作为主强调色，灰白色作为主要背景体系。
- 正文、辅助信息、边框和背景形成明确的四级明度关系。
- 不依赖阴影区分所有区域；优先使用留白、细边框和浅色背景建立层级。

### 克制装饰

- 不使用背景插画、纹理图片、持续发光或大面积渐变。
- 圆角、阴影和动画只用于表达可交互状态。
- 控件保持紧凑，避免将启动器的大型导航结构照搬到剪贴板工具。

### 快速反馈

- 所有指针反馈在 100–180ms 内完成。
- 动效不阻塞点击、键盘选择、滚动或剪贴板恢复。
- 高对比度模式或系统关闭动画时禁用非必要动画。

## 窗口结构

### 窗口框架

- 保留无边框窗体、任务栏入口、标题栏拖动和右上角关闭行为。
- 窗口宽度保持 600px，设计高度保持 1200px，并继续按当前显示器工作区自动限制实际高度。
- 四边显示统一的 1px 边框，使用系统阴影增强窗口与桌面的分离感。
- 标题栏采用纯白背景，左侧增加 4px 蓝色识别条。
- 标题文字使用半粗字重；关闭和设置入口采用无边框图标按钮。

### 搜索区域

- 搜索框高度约 46–48px，使用浅色背景、8px 视觉圆角和 1px 边框。
- 左侧显示搜索图标，右侧在存在输入时显示清空按钮。
- 默认边框为浅灰色；获得焦点时在 120ms 内过渡为蓝色。
- 搜索防抖、占位文字和搜索逻辑保持不变。

### 筛选区域

- 使用水平分段标签替代传统按钮视觉。
- 选中项使用浅蓝背景、蓝色文字和半粗字重；非选中项保持透明背景和中灰文字。
- “全部”标签可显示当前已加载数量，其余筛选项不强制显示数量。
- 点击筛选项时仅改变视觉状态和查询条件，不增加页面切换层级。

### 历史列表

- 列表背景使用极浅灰蓝色，卡片使用白色背景。
- 每条记录采用 8px 视觉圆角、1px 浅灰边框和轻微静态阴影。
- 文字记录左侧显示统一的文本类型图标；图片记录显示 44–52px 缩略图。
- 主内容最多显示两行，保持省略号和严格裁剪。
- 第二行辅助信息显示时间、内容类型及可用的图片尺寸或缓存大小。
- 收藏入口固定在右侧，悬停时增强蓝色，不改变现有单击收藏行为。

## 状态设计

### 默认状态

- 卡片为白色背景、浅灰边框，无明显位移。
- 时间和类型信息使用辅助文字色。

### 悬停状态

- 在约 100ms 内将边框过渡为浅蓝色。
- 背景轻微提亮，并向右移动最多 2px。
- 阴影透明度略微增强，但不产生明显浮层感。

### 选中状态

- 使用浅蓝背景、蓝色边框和清晰的键盘焦点标识。
- 选中状态优先级高于悬停状态。
- 单击仍然只选中；双击或 Enter 才应用内容。

### 空状态

- 列表为空时显示简洁线性图标、标题和一行说明。
- 搜索无结果时显示“没有匹配的历史记录”，并提供清空搜索提示。
- 空状态不改变搜索框和筛选栏位置，避免布局跳动。

### 加载和错误状态

- 加载更多记录时在列表底部显示轻量状态文字，不使用阻塞式遮罩。
- 查询失败继续在底部状态栏显示错误信息。
- 动画或绘制异常不得影响剪贴板监听和托盘进程。

## 动效规范

- 窗口显示：160ms，透明度渐显并向上移动约 8px。
- 窗口隐藏：120ms，仅渐隐；隐藏完成后保持后台进程运行。
- 卡片悬停：100ms，背景、边框、阴影和最多 2px 位移。
- 卡片选中：120ms，浅蓝背景和蓝色边框过渡。
- 筛选切换：140ms，背景和文字颜色过渡。
- 删除记录：180ms，透明度降低并收起占用高度；数据删除成功后才执行视觉移除。
- 所有动画使用统一的 ease-out 缓动，不使用弹簧、回弹或连续循环动画。

## WinForms 实现策略

- 继续使用现有 owner-drawn ListBox，不迁移到 WPF 或 WinUI。
- 将卡片颜色、边框、位移和透明度状态保存在轻量视图状态对象中。
- 使用单个 16ms WinForms Timer 驱动可见列表项动画，窗口隐藏或无活动动画时停止计时器。
- 仅重绘状态发生变化的列表项，避免整窗持续刷新。
- 使用 GDI+ 路径绘制视觉圆角；高 DPI 下按当前缩放比例计算边距、圆角和图标尺寸。
- 搜索框、筛选项和标题栏按钮使用可复用的自绘控件或集中式绘制帮助方法，避免散落事件样式代码。
- 动画设置由统一策略判断；高对比度或系统动画关闭时直接应用最终状态。

## 可访问性与键盘操作

- 保留 Alt+V、方向键、Enter、Delete 和 Esc 行为。
- 选中状态必须在浅色和深色系统主题下保持足够对比度。
- 不能只依靠颜色表达选中状态；同时使用边框和焦点标识。
- 所有图标按钮保留可访问名称和工具提示。
- 高对比度模式继续使用系统颜色，不强制应用品牌配色。

## 性能约束

- 不新增第三方 UI 或动画依赖。
- 无活动动画时不得产生持续刷新或显著 CPU 占用。
- 窗口打开和滚动过程中不重复解码已加载缩略图。
- 动画只作用于当前可见列表项。
- 后台监听、SQLite 写入和图片保存不得切换到 UI 线程。

## 测试与验收

- 自动化测试确认窗口尺寸、自适应高度、四边边框和现有窗口行为不回退。
- 自动化测试确认搜索框、筛选栏和列表使用新的控件层级。
- 自动化测试确认单击、双击、Enter、Delete 和收藏行为保持不变。
- 自动化测试确认高对比度或禁用动画时直接使用最终视觉状态。
- 自动化测试确认动画计时器在无活动动画和窗体隐藏时停止。
- 人工验证 100%、125%、150% 和 200% DPI 下无裁剪、重叠或模糊边框。
- 人工验证长文本、图片记录、空列表、搜索无结果和大量滚动状态。
- 人工验证动画流畅且不延迟剪贴板内容应用。

## 非目标

- 不逐像素复制 PCL2，也不使用其图片、图标或品牌资源。
- 不增加侧边导航、背景壁纸或启动器式页面结构。
- 不迁移到 WPF、WinUI 或 WebView。
- 不改变历史数据模型、保留策略、监听机制或存储格式。
- 不在本轮重做设置窗口和清空历史对话框；它们可在历史窗口风格稳定后单独统一。
